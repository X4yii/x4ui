# X4UI Framework

A standalone, flexible, and dynamic UI framework for Minecraft Forge 1.12.2 mods.

## Features
- **GuiPanel & GuiScrollPanel**: FlexBox-style containers and native OpenGL clipping.
- **Component Based**: Easy creation of dynamic interfaces.
- **Micro-Animations**: Smooth lerp-based hover and click animations.

## Usage via JitPack

Add the following to your `build.gradle`:

```gradle
repositories {
    maven { url 'https://jitpack.io' }
}

dependencies {
    compile 'com.github.X4yi:X4UI:1.0.0'
}
```
